4. 🔑 Authentication Workflow & ComponentsThe frontend must manage the user's logged-in status via the JWT.A. AuthProvider.jsx (Global State)State: Holds the jwtToken (string) and user object (fullName, email).Initialization: When the app loads, check localStorage for an existing JWT. If found, set the global state.Logout Function: Clears state and removes the JWT from localStorage.B. ProtectedRoute.jsxA component wrapper that checks the useAuth() state. If no valid JWT is present, it redirects the user to the /login page.C. LoginPage.jsxDesign: Simple page displaying the company logo and a large "Login with Google" button.Action: Clicking the button performs a client-side redirect to the Golang endpoint:JavaScriptwindow.location.href = `${VITE_API_BASE_URL}${API_LOGIN_ENDPOINT}`;
